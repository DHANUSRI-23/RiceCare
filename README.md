# 🌾 RiceCare: AI-Powered Rice Crop Decision Support System

## 🚀 Overview

RiceCare is an AI-driven web application designed to assist farmers in making smarter decisions for rice cultivation. It integrates machine learning, deep learning, and real-time weather data to provide yield prediction, crop analysis, and actionable recommendations.

The primary goal of RiceCare is to **improve crop yield productivity** by providing intelligent, data-driven insights in a simple and accessible way.

## 🎯 Problem Statement

Farmers often struggle with:

* Uncertainty in predicting crop yield
* Difficulty in identifying plant health issues
* Lack of real-time decision support
* Reduced productivity due to inefficient decision-making

---

## 💡 Solution

RiceCare provides:

* 📊 **AI-based Yield Prediction**
* 🍃 **Leaf Analysis for Crop Health**
* 🌦️ **Real-time Weather Insights**
* ✔ **Smart Recommendations to improve yield productivity**
* 🌍 **Multi-language Support (English & Tamil)**

---

## 🧠 Features

### 🌾 Yield Prediction

* Predicts rice yield using:

  * Weather conditions
  * Cultivation inputs
  * Seasonal factors
* Uses Machine Learning (XGBoost) for accurate predictions
* Helps farmers **plan better to maximize yield output**

---

### 🍃 Crop Health Analysis

* Upload a leaf image
* Detects crop issues using Deep Learning (CNN)
* Provides:

  * Cause of the issue
  * Recommended actions
  * Preventive measures
* Helps prevent losses and **maintain healthy crop growth**

---

### 🌦️ Weather Insights

* Integrates real-time weather data
* Helps users understand environmental conditions affecting crops
* Supports better planning for improved productivity

---

### 🌐 Multi-language Support

* Supports:

  * English
  * Tamil
* Designed for accessibility and ease of use
